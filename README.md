# AuraElevates

Production website for AuraElevates, a first-person filming and editing company using Ray-Ban Meta smart glasses to capture events, brands and experiences from inside the moment.

## Stack

- React 19
- Vite
- Vanilla CSS
- Vercel

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
npm run preview
```

The live domain is [auraelevatesco.com](https://www.auraelevatesco.com/).
